# BookMyTicket

A full-stack movie ticket booking application built using Java and Spring Boot.

## Technologies Used

- Java
- Spring Boot
- Spring MVC
- Hibernate
- JPA
- MySQL
- Thymeleaf
- REST APIs
- JWT
- Redis
- Cloudinary
- Razorpay
- JavaMailSender
- Maven

## Features

- User registration and authentication
- Movie management
- Theatre management
- Show scheduling
- Movie ticket booking
- Seat selection
- JWT-based authentication
- OTP verification
- Online payment using Razorpay
- Movie image hosting using Cloudinary
- Email notifications
- Redis-based OTP/session management
- Centralized exception handling
- Input validation

## Run Locally

1. Clone the repository.
2. Configure MySQL and the required application properties.
3. Configure Redis, Cloudinary, Razorpay, and email credentials.
4. Build and run the Spring Boot application using Maven.

```bash
mvn spring-boot:run

```
